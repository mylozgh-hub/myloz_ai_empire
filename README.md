# Myloz Binance Spot Scanner

A Python Binance Spot market scanner.

## Safety

- Real trading is disabled by default.
- Configure API credentials through environment variables.
- Never commit API keys, secrets, or account state files.
- Test in safe mode before enabling real trading.

## Setup

Install dependencies:

    pip install -r requirements.txt

Run the scanner:

    python myloz_live_spot_scanner.py
